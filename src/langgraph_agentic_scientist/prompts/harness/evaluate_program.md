Run the task's official evaluator on one program directory (`program_dir`, relative to your working directory) and publish the validated `metrics.json`, `correct.json` and `evaluation_manifest.json` at the program root. The call is blocking and returns when the evaluation has finished. Every call consumes one evaluation of the attempt's budget, including calls that fail or are interrupted; a call made after the budget is consumed is refused without evaluating. The result names the evaluator's output directory (`evaluation outputs:`) and summarizes the outcome.
